# Installing Little Ramadan

Little Ramadan is a web app. Installing it is free and needs no app store.

## iPhone / iPad (Safari)
1. Open the Little Ramadan link in **Safari**.
2. Tap the **Share** button (square with an arrow).
3. Tap **Add to Home Screen**, then **Add**.
4. Open it from the home screen once while online; after that it works offline.

## Android (Chrome)
1. Open the link in **Chrome**.
2. Tap **Install app** when offered, or open the ⋮ menu → **Install app** / **Add to Home screen**.
3. Open it once while online; after that it works offline.

## Computer (Chrome / Edge)
Click the install icon in the address bar, or just use it in the browser.

Note: on iPhone, the installed app keeps its own storage, separate from Safari. Set up the profile inside the installed app.
